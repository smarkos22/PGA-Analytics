# Public portfolio maintenance

This repository contains selected source, invented examples, and offline tests.
README.md and docs/SOURCE_SELECTION.md define its supported scope.

- Keep credentials, personal records, provider datasets, screenshots, and original
  operational context/history out of this repository.
- Review comments, docstrings, test fixtures, Git history, and Actions output;
  a successful secret scan alone does not establish privacy clearance.
- Every tracked file must be explicitly reviewed in PUBLICATION_FILES.txt.
- Run scripts/check_publication.py, the documented tests, and full-history secret
  scanning before publishing. Use a GitHub noreply commit email.
- Keep this file and AGENTS.md aligned. Store private audit evidence and session
  handoffs outside the repository; do not copy them into public context files.
- Update source-selection notes when changing publication scope or behavior.
